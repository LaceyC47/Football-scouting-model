## Milestone 3 — Data Intelligence and DM Model Foundation

Milestone 3 audits the real 2025–26 player dataset and creates reproducible reports covering
column structure, missingness, duplicate metadata, position distributions and the eligible
midfielder pool.

Run:

```bash
python scripts/audit_dataset.py
```

The current dataset supports a provisional defensive-activity analysis but does not yet contain
the passing, carrying and possession-security detail required for a complete defensive-midfielder
profile model.
